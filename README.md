# env-demo

Учебный репозиторий к занятию 7 курса по Claude Code: безопасность проекта.

Посмотри на список файлов выше. Файла `.env` здесь нет, хотя на компьютере автора он лежит
рядом с `index.html`. Его не пускает файл [`.gitignore`](.gitignore): всё, что в нём
перечислено, git на GitHub не отправляет.

Зато есть [`.env.example`](.env.example): шаблон с именами секретов и без значений. По нему
видно, какие ключи нужны проекту, а сами ключи остаются у владельца.

Курс: https://github.com/ahtlv/claude-course-lesson-7
